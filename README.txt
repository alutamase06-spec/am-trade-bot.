AM TRADE BOT PRO — VERSION 2

Configured as requested:
- Markets: Forex and Crypto
- Strategy: EMA 9 / EMA 21 trend-following crossover
- Platform: responsive web app for computer and Android
- Risk: 1% of demo balance per trade
- Demo account: R10,000
- Stop-loss: 2% adverse price move
- Take-profit: 4% favorable price move
- Maximum concurrent demo positions: 2

IMPORTANT:
This is a paper-trading simulator. All market prices are generated in the browser.
It has no broker/exchange connection and cannot place real-money trades.
A simulated result is not a forecast of actual trading performance.

PUBLISH / INSTALL:
1. Extract this ZIP.
2. Upload index.html, manifest.webmanifest, and sw.js to a static HTTPS host.
3. Open the published URL in Chrome on Android.
4. Use Chrome menu > Install app / Add to Home screen.
5. On a computer, open the same URL in Chrome or Edge; use the install icon/menu if offered.

The app needs HTTPS for reliable PWA installation and offline caching.
